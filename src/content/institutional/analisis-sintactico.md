# Análisis sintáctico

El análisis sintáctico estudia la función que cumple cada palabra dentro de una oración y la relación entre los distintos elementos que la componen.

## Ideas clave
- El sujeto es el elemento del que se dice algo.
- El predicado expresa lo que se afirma del sujeto.
- El núcleo del sujeto suele ser un sustantivo o pronombre.
- El núcleo del predicado suele ser un verbo conjugado.

## Recomendación de estudio
- Identifica primero el verbo principal.
- Luego separa sujeto y predicado.
- Finalmente analiza complementos y modificadores.
